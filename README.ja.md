# 🌸 ナーム・ジャプ・カウンター

**ナーム・ジャプ・カウンター**は、信者が**ラーダー・ナーム・ジャプ**を簡単かつ集中して数えることができる、穏やかでインタラクティブなウェブアプリです。美しくデザインされたインターフェースを通して、唱え、音声を聞き、祈りの記録を管理しながら、神聖な喜びに浸ることができます。

![ナーム・ジャプ・カウンター](https://github.com/KrishBharadwaj5678/NaamJapCounter/raw/main/NaamJapCounterDemo.png)

## ⚙️ 機能

| 機能                   | 説明                                      |
| -------------------- | --------------------------------------- |
| 👆 **タップでカウント**      | 画面のどこをタップしてもラーダー・ナームをカウントできます。          |
| 🎧 **ラーダー・ナーム音声**    | **プレマナンド・マハラジ・ジ**によるラーダー・ナームの音声が再生されます。 |
| 🔇 **ミュート / ミュート解除** | 好みに応じて音声を切り替えできます。                      |
| 🌓 **ダーク＆ライトモード**    | 穏やかなダークモードと明るいライトモードを切り替え可能です。          |
| ⏱️ **タイマー**          | 祈りのセッション時間を記録します。                       |
| 🔢 **総ジャパ数**         | ラーダー・ナームの合計回数を表示します。                    |
| 📿 **マーラーカウンター**     | 完了したマーラー（周回数）を自動でカウントします。               |
| 🎉 **紙吹雪エフェクト**      | 100回ごとの達成時に紙吹雪で祝います。                    |
| 🖥️ **フルスクリーンモード**   | 全画面で集中して祈りに没頭できます。                      |
| 📱 **レスポンシブデザイン**    | モバイル・タブレット・デスクトップに対応しています。              |

## 🛠️ インストール方法

### 1️⃣ リポジトリをクローン

```bash
git clone https://github.com/KrishBharadwaj5678/NaamJapCounter.git
```

### 2️⃣ プロジェクトフォルダへ移動

```bash
cd NaamJapCounter
```

### 3️⃣ 依存関係をインストール

```bash
npm install
```

### 4️⃣ 開発サーバーを起動

```bash
npm run dev
```

### 5️⃣ ブラウザでアプリを開く

```text
http://localhost:5173
```
