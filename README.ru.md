# 🌸 Счётчик Нам Джап

**Счётчик Нам Джап** это спокойное и интерактивное веб-приложение, которое помогает преданным легко и с концентрацией считать свой **радха-нам джап**. Погрузитесь в духовное блаженство, повторяя мантры, слушая аудио и отслеживая свою практику через красиво оформленный интерфейс.

![Счётчик Нам Джап](https://github.com/KrishBharadwaj5678/NaamJapCounter/raw/main/NaamJapCounterDemo.png)

## ⚙️ Возможности

| Функция                      | Описание                                                                        |
| ---------------------------- | ------------------------------------------------------------------------------- |
| 👆 **Нажатие для счёта**     | Счёт радха-нам происходит простым нажатием на экран.                            |
| 🎧 **Аудио Радха-нам**       | Воспроизведение Радха-нам в исполнении **Премананда Махарадж Джи** при нажатии. |
| 🔇 **Вкл/выкл звук**         | Возможность включать и выключать звук по желанию.                               |
| 🌓 **Тёмная и светлая тема** | Переключение между спокойной тёмной и светлой темой.                            |
| ⏱️ **Таймер**                | Отслеживание времени вашей практики.                                            |
| 🔢 **Общее количество джап** | Отображает общее число повторений Радха-нам.                                    |
| 📿 **Счётчик мала**          | Автоматически считает завершённые круги (малы).                                 |
| 🎉 **Конфетти-эффект**       | Празднование каждых 100 повторений с анимацией конфетти.                        |
| 🖥️ **Полноэкранный режим**  | Полное погружение в практику без отвлекающих элементов.                         |
| 📱 **Адаптивный дизайн**     | Работает на мобильных устройствах, планшетах и компьютерах.                     |

## 🛠️ Установка

### 1️⃣ Клонировать репозиторий

```bash
git clone https://github.com/KrishBharadwaj5678/NaamJapCounter.git
```

### 2️⃣ Перейти в папку проекта

```bash
cd NaamJapCounter
```

### 3️⃣ Установить зависимости

```bash
npm install
```

### 4️⃣ Запустить сервер разработки

```bash
npm run dev
```

### 5️⃣ Открыть приложение в браузере

```text
http://localhost:5173
```
