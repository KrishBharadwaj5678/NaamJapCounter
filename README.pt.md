# 🌸 Contador de Naam Jap

**Contador de Naam Jap** é um aplicativo web calmo e interativo que ajuda os devotos a contar seu **Radha Naam Jap** com facilidade e concentração. Mergulhe na paz espiritual enquanto canta, ouve e acompanha sua devoção por meio de uma interface bonita e bem projetada.

![Contador de Naam Jap](https://github.com/KrishBharadwaj5678/NaamJapCounter/raw/main/NaamJapCounterDemo.png)

## ⚙️ Funcionalidades

| Funcionalidade                | Descrição                                                   |
| ----------------------------- | ----------------------------------------------------------- |
| 👆 **Toque para contar**      | Conte o Radha Naam simplesmente tocando na tela.            |
| 🎧 **Áudio do Radha Naam**    | Reproduz o Radha Naam de **Premanand Maharaj Ji** ao tocar. |
| 🔇 **Ativar / Desativar som** | Ligue ou desligue o som conforme sua preferência.           |
| 🌓 **Modo claro e escuro**    | Alterne entre modo claro e escuro.                          |
| ⏱️ **Cronômetro**             | Acompanha o tempo da sua sessão de japa.                    |
| 🔢 **Contagem total de japa** | Mostra o total de repetições do Radha Naam.                 |
| 📿 **Contador de mala**       | Conta automaticamente as malas (voltas) concluídas.         |
| 🎉 **Efeito de confete**      | Celebra cada 100 repetições com confete.                    |
| 🖥️ **Modo tela cheia**       | Foco total na prática espiritual em tela cheia.             |
| 📱 **Design responsivo**      | Funciona perfeitamente em celular, tablet e desktop.        |

## 🛠️ Instalação

### 1️⃣ Clonar o repositório

```bash
git clone https://github.com/KrishBharadwaj5678/NaamJapCounter.git
```

### 2️⃣ Entrar na pasta do projeto

```bash
cd NaamJapCounter
```

### 3️⃣ Instalar dependências

```bash
npm install
```

### 4️⃣ Iniciar o servidor de desenvolvimento

```bash
npm run dev
```

### 5️⃣ Abrir o aplicativo no navegador

```text
http://localhost:5173
```
